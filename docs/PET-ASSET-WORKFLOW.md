# 桌宠素材经验与 Skill 使用指南

2026-11-17 以 `806794f`（v0.3.0 Build 25）为基线整理，纳入后续交互反馈。实际素材、选项和代码契约以当前工作区和最新要求为准。

## 最值得保留的经验

1. **同一只猫先统一底子，再替换零件。** 新品种尽量复用形状、动作与锚点，通过底毛、花纹、浅毛和左右耳配色适配。只有真实轮廓变化才新增对应形状。不要每个品种、每个动作、每种配色各重画一张完整猫。
2. **按用户能编辑的内容分层。** 耳朵、鼻子、嘴巴、眼睛/内瞳/高光、脸部底纹、额纹、脸颊纹、身体花纹、左右前爪、尾形、尾纹和配饰有各自边界。同一张素材可以用图层或遮罩承担多个独立部位。
3. **只改目标区域，需要两种证据。** 锁层逐帧 RGBA diff 为 0，证明原层未动；合成图范围检查，证明新层没有覆盖无关区域。二者都通过后再看整体视觉。
4. **透明不等于抠干净。** alpha 只有 0/255 仍会有不透明灰点、旧描边和接缝漏底。用浅底、深底、实际大小与最近邻放大检查耳尖、胡须、爪底、尾根、电脑上沿和动作隐藏处。
5. **描边按整体判断。** 颜色随毛色协调，粗细贴合相邻部位。手掌上半圈加粗可向内局部修改，下半圈保留；不能一律把全图边缘加黑加粗。换线色靠原始线稿/语义遮罩，不能替换所有暗色像素。
6. **动作和纹理分别维护。** 手掌升降，固定前臂花纹不动。清掉旧爪时不能用大块纯色抹掉虎斑；恢复纹理还要排除旧爪残线。慢打、较快、特别快复用低抬爪，主要靠节奏变化，努力表情与汗水独立叠加。
7. **动画和自定义不能互相覆盖。** 用户画的内容保存为相对原底稿的笔迹/遮罩，并按部位定位。换外观、跟随高光、继续打字仍可工作；旧底稿版本必须可还原，否则旧姿势和杂边会误变成用户笔迹。
8. **源稿、导出、运行、保存必须同一契约。** 图层名、帧数、时序、图集布局、换色遮罩、坐标和工作台保存元数据一起核对。构建成功只说明构建成功，不能代替拼接和美观验收。
9. **工具连接要实际验证。** MCP 工具注册、Aseprite 打开、历史曾连接、当前可调用是不同事实。先用真实调用定位故障，再检查两端端口，保留旧会话；绘制前停止播放，导出超时后不能误用旧图片。

## 后续修改沉淀的经验

| 场景 | 下次直接复用的做法 |
| --- | --- |
| 加品种或换零件 | 同轮廓品种先登记稳定 ID 和底毛、花纹、浅毛三色，按需选用已有模板。按素材清单找到当前源稿与导出组，核对鼻嘴接点、尾根和遮挡。尾形还原以参考图的像素台阶为准，清边时只修飞点。 |
| 三档打字及表情 | 复用正视坐姿、电脑和低抬爪。把字母、落地粒子、热色和蒸汽按各自坐标叠加。改某档时固定同一品种、同一帧，比对角色像素及其他档位。旧字母轨迹随 `typingAnimation` 版本还原，避免写入自定义笔迹。 |
| 拆分脸部与身体纹理 | 先看「三花脸＋纯色身体」和「均匀脸底＋虎斑身体」，再扩到其他品种。保留原白胸比例，重点对比三花色块、重点色接缝，以及切均匀底色后的眼缘。 |
| 贴边或果冻拖动 | 先判断渲染、鼠标时序与原生窗口位置。头身需要一起露出时使用整张坐姿的连续轮廓，爪和尾巴的运动按已有遮罩定位。用原生事件和像素比对分别验收。 |
| 切状态才露出的脏点 | 先固定品种和动作帧，只切换触发问题的选项。挤眼检查完整旧眼圈，按邻近毛色修复后再叠挤眼线。无额纹时检查两侧耳根向内多出的描边，在保留轮廓和自然色区的前提下补色。 |
| 自定义存档和构建 | 新档按部位保留笔迹和擦除，旧 PNG 先重建旧底稿再提取改动。有元数据和只有 PNG 的旧档各测一次。用户存档放在应用数据目录，内置资源通过素材清单进入构建。 |
| 工作台外观控件 | 直接核对原生工作台。左右眼独立，单瞳和双瞳切换后继续显示对应颜色。内耳色、瞳色、鼻色、毛色的色块在菜单内各选项右侧，原色取当前品种的代表色。 |
| 上传 GitHub | 提交前核对代码、源稿与运行素材，评审截图和用户存档留在本机。终端缺凭据时可使用已有写权限的 GitHub 连接，并校验远端提交的文件树和分支头。 |

## 项目需求速记

- 内置品种依次为橘猫、黑猫、英短、美短、狸花、三花、暹罗、布偶。选品种恢复整套默认外观，之后仍可调整。姓名与独立自定义笔迹按各自规则保留。各品种色板也进入「毛色搭配」，供其他品种直接选用。
- 鼻子和嘴巴独立组合。脸部底纹、脸颊花纹、额头花纹、身体花纹和尾纹独立选择，身体花纹只管躯干和四肢。三花、暹罗和布偶可切换品种原底与均匀底色，其余内置品种显示均匀底色。三花脸配纯色身体保留原白胸比例。
- 外观依次为耳朵、眼睛、鼻子、嘴巴、尾形与尾纹。接下来同排是额头花纹、脸部底纹、脸颊花纹，再往下是身体底色和身体花纹。左右眼分别选单瞳或双瞳，双瞳显示两组可独立设置的颜色。
- 头顶配饰与服装配饰分开。服装暂无素材时显示「无」。
- 高光小，鼠标跟随只移动高光；开跟随隐藏静态高光，避免出现两份。
- 自定义编辑从当前预览开始，笔刷保留方块/圆点、粗细与颜色；保存后外观仍可编辑、动画仍可播放。
- 待机和打字沿用同一个正视坐姿。落爪全部藏在电脑实边下，左右落爪留出间隔。慢档微笑、比较快严肃嘴、特别快挤眼配奔驰嘴。特别快档的电脑升温到红色后持续冒汽。
- 不再新增 Walk；不恢复粉色书包、红围巾或“打字猫配饰”。历史文件可能保留用于兼容。
- 用户要求先看时，完成独立候选后等确认；已授权导入时继续完成，不另设重复审批。

## 原生交互的验收口径

- **贴边探头**。释放所在屏幕的左下角和右下角沿用底边探头姿势，窗口贴在可用桌面内侧，给 Dock 留出空间。Dock、底边中间、侧边较高处和浏览器窗口边缘均按普通拖动处理。旧的 Dock 和其他边缘记录会恢复为附近的完整坐姿。
- **橘猫果冻拖动**。复用现有正面坐姿和既有遮罩。鼠标速度驱动头、身体和尾巴，四爪固定。身体延后 100 ms，尾巴最慢且摆幅最大。拉伸最多 15%，倾斜最多 5°。松手使用 180 / 12 / 1 的弹簧参数，身体先收、头晚 50 ms，弹动 2–3 下停稳。
- **每日打字统计**。界面展示今日按键次数和活跃时长，按本地日期保存。活跃时长累计相隔最多 5 秒的按键间隔，显示层可独立调整。
- **Mac 文件整理**。右键选桌面或系统选取的一个目录，预览列出每个文件的来源与去向。按修改月份、可选关键词和扩展名类别整理，用户点开始才移动，结果可依本地记录撤销。测试用临时目录覆盖保护项、冲突、权限提示、重开后的撤销和单目录范围。

具体代码入口和测试样例见 [macOS 桌宠交互](/Users/mac/.codex/skills/desktop-pet-asset-integration/references/desktop-interactions.md)。

## 一次任务如何交付

先核对参考与实际底稿，判断需要画形状还是改组合代码；绘制时保留源稿、局部边界与基准。先检查关键姿势和整体，再补帧与局部细节。审阅交付源稿、整猫预览、关键帧/动图和验证结果；正式接入再补运行时组合、旧存档、构建与真实工作台验证。

用户可以直接说：“用 Aseprite Skill 调整慢打手掌，先预览”，或“把确认后的版本导入工作台，检查其他品种与自定义”。无需每次重新列完整检查流程。

## 当前素材入口

当前三档打字使用 `front-v6` 的正视电脑，循环每帧分别为 70、40、20 毫秒。三档的字母都弹起再落地，每圈分别弹出 8、12、18 个字母。特别快档全程使用挤眼与奔驰嘴，叠加电脑红温与蒸汽。旧 `front-v5`、`front-v4`、`front-v3`、`reference-v2` 与 `reference` 资源继续用于重建相应版本的底稿。实际运行文件、源稿及导出命令参见[素材清单说明](ASSETS.md)。
