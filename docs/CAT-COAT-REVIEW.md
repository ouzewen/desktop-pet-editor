# 猫咪照片生成与花色验收

这套流程用于把猫照片转换成当前桌宠风格。先从已收集的照片挑出重复出现的特征，绘成独立零件。上线后，照片识别负责提供部位、左右、颜色类别、覆盖档位和照片来源。App 按这些信息挑选已审核零件，按动作图层合成。

## 建立素材

1. **从实照标特征。** 先记部位、画面方向和相对面积，例如小白下巴配宽白胸、单侧额眼深斑、侧腰大斑。多视角能确认时，记录是哪张照片看清楚的。
2. **在 Aseprite 画独立零件。** 以现有猫底稿的 320×320 坐标和像素网格为基准。通过 MCP 在独立图层绘制边缘和明暗。尺寸变体共用原部位锚点。胸口、躯干、左右前肢分层，以便组合和遮挡。
3. **审核并登记。** 保留分层 `.aseprite` 和独立 PNG，为通过验收的零件登记部位、侧别、覆盖档位、锚点、兼容底稿和遮挡顺序。同一部位的不同面积互为备选。确实可见、具有辨识价值的细小标记可以用手动微调补齐。
4. **用 AI 选件。** AI 输出识别信息，App 从素材库查找零件。匹配时先对部位和左右，再对面积与颜色。缺少足够照片证据时，可省去次要标记。预绘素材需先验收，现有程序化模板仍属于早期方案。

## 组合验收

- 先从可辨认的照片确认主色、左右分布和最醒目的标志，例如小白下巴、白胸是否连到肩膀，或哪侧眼周有深斑。先确定它在哪一侧、占该部位多大，再选模板。覆盖比例按照片中可见的同一部位估计。小、中、大斑共用锚点，边界可简化成连贯的几段像素。细小标记仅在清楚可见且有辨识价值时保留。
- 在桌宠实际显示大小检查整只猫。斑块沿部位轮廓和现有明暗合成。核对额顶与眼周、白下巴与胸肩、躯干与前肢的边缘，让相接的毛色连续，让不同部位维持正确的遮挡。
- 自动生成验收用未经手调的配置，对照原图与固定帧的待机和「特别快」。同时检查这一眼能否认出照片里的标志、组合的边缘和色阶是否自然，以及切换动作后露出的花纹是不是同一块。

### 浏览器评审

在项目根目录运行 `node scripts/coat-review/server.mjs`，打开 [本地评审页](http://127.0.0.1:4179)。默认载入第十三轮宽胸与白肩修订，候选并排显示待机和特别快打字，可播放打字循环。查看第十二轮时，启动命令可附加 `scripts/coat-review/round-12.json`。评审页导航中的「内部素材库」分为整体形象和单独组件。整体形象提供整猫待机、特别快打字和所用组件链接。组件卡片直接显示透明素材，并提供 Aseprite 源稿。组件可按大类、部位和具体位置筛选。每组可勾选多个候选，也能用「全选」一次勾选当组全部候选。勾选「都不选」会清掉当组选项，可通过文字或点绘留下修改意见。未提交的草稿保存在当前浏览器里，各轮提交写入各自的 `output/coat-review-round-XX-feedback.json`。

第十轮和第十一轮候选卡支持右耳像素微调。提交保存候选编号、改色、分界和耳尖标注，原稿仍可随时对照。反馈文件里的 `retouches` 按候选编号保存，每个像素地址是 `y * 320 + x`。改色使用六位 RGB，分界可含多点，耳尖为单点。待机和打字预览读取改色，放大编辑画布同时显示标注。

第 14 轮 B3 的微调画布对准前肢横环，B4 对准胸肩，可放大逐格点绘。两组的改色在待机图上预览，打字图提供原稿参考。以后可以在对应组的 `retouch` 配置里填写裁切坐标与部位名称，让候选卡显示「像素微调」。只在待机预览改色的组使用 `idleOnly: true`。

下一轮按 `scripts/coat-review/round-03.json` 的结构填写新的轮次文件，引用 `output/` 中相应的原图和试装图。启动时传入该文件的路径，页面按文件中的轮次和分组显示，提交结果按轮次保存。

## 内部选件库

自动生成用的零件登记在 `src/pet-assets.ts` 的 `catPhotoParts`。每项有稳定编号、部位、侧别、颜色、覆盖范围、兼容底稿和分层源稿。照片识别返回特征，选件规则根据证据选择相符的已审核编号。成品外观保存所选编号，运行时在头脸或躯干图层合成，用户界面只提供照片生成和既有手动微调。

`art/cat-shared/photo-coat-parts/` 收录候选和修订源稿。上线 PNG 由登记的独立图层导出到 `public/assets/cat/hd/photo-coat-parts/`。待审核的图层留在源稿库，自动选件只读取运行清单中的已审核编号。当前已接入 Shappo 的 A3 底毛、小白下巴和小白胸，以及三花的 C3 连片白胸。Push 的 B3R 已通过第四轮评审并接入自动选件。三花头部的 H3R3 已通过第六轮评审。修边归入深色额顶、画面左侧橘色宽眼周的固定头部样式。旧存档中的修边编号会迁移到该样式版本。

### 组件部位

`catPhotoPartTaxonomy` 定义大类、部位和具体位置，`catPhotoParts` 中每个组件的 `regions` 引用一个或多个位置。左右以正面预览画面为准。照片有不同视角时，识别流程先统一方向，再映射到预览坐标。

- 头部分为额头、眼周、脸颊、面部中心和耳朵。面部中心细分为鼻梁、口鼻和下巴。耳朵、眼周和脸颊可独立登记画面左侧和右侧。
- 立耳的左耳和右耳各有独立选件槽。每耳按靠头顶／靠外轮廓与短耳尖／半耳弧边／满耳到根组合选择。视觉模型单独识别耳斑，Mac 对照耳尖两侧的局部毛色采样。补图需可对齐到首图的同一只耳。12 个形状共用一份分层源稿，PNG 在运行时按该耳的照片颜色适配，保留色阶、内耳及描边。
- 身体分为胸口、肩部、躯干、前肢与前爪、尾巴。肩、侧腰、前肢和前爪各分左右，尾巴分根部、中段和尾尖。
- 整体底毛收录全身配色与明暗。跨部位组件填多个 `regions`，共用源稿和素材编号。例如 Push B3R 覆盖左右额头及右耳。

`slot` 用于渲染与组合的层级约束，`regions` 用于定位和查找组件。首批组件只覆盖已经验收的部位，未覆盖的位置在筛选时显示为空。

同底稿的 24 张组合试装、正面绘制窗和各部位面积见[猫咪花色组件绘制指引](CAT-COAT-COMPONENT-GUIDE.md)。
