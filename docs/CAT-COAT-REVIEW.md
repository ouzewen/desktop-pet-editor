# 猫咪照片生成与花色验收

这套流程用于把猫照片转换成当前桌宠风格。先从已收集的照片挑出重复出现的特征，绘成独立零件。上线后，照片识别负责提供部位、左右、颜色类别、覆盖档位和照片来源。App 按这些信息挑选已审核零件，按动作图层合成。

## 建立素材

1. **从实照标特征。** 先记部位、画面方向和相对面积，例如小白下巴配宽白胸、单侧额眼深斑、侧腰大斑。多视角能确认时，记录是哪张照片看清楚的。
2. **在 Aseprite 画独立零件。** 以现有猫底稿的 320×320 坐标和像素网格为基准。通过 MCP 在独立图层绘制边缘和明暗。尺寸变体共用原部位锚点。胸口、躯干、左右前肢分层，以便组合和遮挡。
3. **审核并登记。** 保留分层 `.aseprite` 和独立 PNG，为通过验收的零件登记部位、侧别、覆盖档位、锚点、兼容底稿和遮挡顺序。同一部位的不同面积互为备选。确实可见、具有辨识价值的细小标记可以用手动微调补齐。
4. **用 AI 选件。** AI 输出识别信息，App 从素材库查找零件。匹配时先对部位和左右，再对面积与颜色。缺少足够照片证据时，可省去次要标记。预绘素材需先验收，现有程序化模板仍属于早期方案。

## 组合验收

- 先从可辨认的照片确认主色、左右分布和最醒目的标志，例如小白下巴、白胸是否连到肩膀，或哪侧眼周有深斑。先确定它在哪一侧、占该部位多大，再选模板。覆盖比例按照片中可见的同一部位估计。小、中、大斑共用锚点，边界可简化成连贯的几段像素。细小标记仅在清楚可见且有辨识价值时保留。
- 在桌宠实际显示大小检查整只猫。斑块沿部位轮廓和现有明暗合成。核对额顶与眼周、白下巴与胸肩、躯干与前肢的边缘，让相接的毛色连续，让不同部位维持正确的遮挡。
- 自动生成验收用未经手调的配置，对照原图与固定帧的待机和「特别快」。同时检查这一眼能否认出照片里的标志、组合的边缘和色阶是否自然，以及切换动作后露出的花纹是不是同一块。

## 候选与反馈

- 每轮给同一个部位或配色 3–4 个有编号的候选，用同一底稿、大小和姿势并排展示。每组集中比较一个变化，例如底毛深浅、额斑覆盖或躯干的色块分布。
- 记录选中的编号和原因。下轮沿用已选的部分，围绕有反馈的部位继续出候选。把反复确认的取舍写进绘制和选件规则。
- 目前优先保留头脸的左右分布和覆盖面积，尤其是白下巴、额顶和眼周。三花躯干可以用更少的色块与较柔和的色阶概括，保留整体深浅和大致分布。
- Shappo 已选「小白下巴＋小胸斑」。继续比较深黑底毛。Push 额顶保留画面左上少量黑色，右上黑色收在眼睛上方。
