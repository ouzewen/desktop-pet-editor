# 猫桌宠素材目录与命名

照片自动生成与整猫花色的验收标准见[猫咪照片生成与花色验收](CAT-COAT-REVIEW.md)。

运行时内置素材根目录是 `public/assets/`，由 Vite 复制到 `build/desktop/assets/` 与 `build/web/assets/`。两个构建均排除旧的用户存档路径 `public/assets/cat/custom/`，桌宠打包时也会检查暂存目录。

macOS 正式构建优先加载 `desktop/assets-pixel80/` 中已验收的 80×80 素材。它们按原坐标放大到运行图层和图集。工作台使用的鼻口、脸部补片、眨眼帧和狂打发热层使用同一套像素网格。

新的像素存档记录 `artVersion: "pixel80-v2"`。第一版 80×80 存档沿用原版素材清单和 `desktop/assets-pixel80-v1/` 中保留的发热层来提取笔迹和擦除。更早的存档使用 `public/assets/` 中的底稿。旧眼型、旧尾型和旧版打字图层用于兼容。

修改这一批素材时，用 `node scripts/stage-cat-pixel80.mjs <组 ID>` 将 `art/cat-pixel80/` 的分层源稿导出到 `output/cat-pixel80/assets/`。先用 `./desktop/build.sh --pixel80-preview` 查看，再把验收过的 PNG 按原相对路径复制到 `desktop/assets-pixel80/`。普通构建直接读取已验收的 PNG。

像素编辑的 PNG、底稿信息和预设清单保存在 `~/Library/Application Support/DesktopPet/custom/`。从项目内打开新版桌宠时，旧工作区存档会合并到此处，原目录备份到同级的 `legacy-custom-backups/`。

## 素材清单与导出

[`src/pet-assets.ts`](../src/pet-assets.ts) 是内置 PNG 的清单。每组记录用途（现役、旧存档兼容、历史库存）、Aseprite 源稿、导出脚本或图层、输出路径和尺寸。工作台读取清单里的零件选项、加载项和尺寸。历史库存留在原路径，只有兼容组进入相关渲染器。无可运行导出流程的素材组在列表中标为 `retained`。

```sh
npm run assets:list
npm run assets:list -- cat.typing.front-v4.frenzy
npm run assets:check
npm run assets:export -- cat.ear.folded --out /tmp/pet-review-assets
```

导出使用清单中的脚本或图层，并在临时目录检查 PNG 是否齐全、尺寸是否正确。审核后可用同一命令省略 `--out`，输出到 `public/assets/`。如果 Aseprite 不在 PATH 中，将 `ASEPRITE_BIN` 设为本机 Aseprite 可执行文件路径。桌宠和 Web 构建都会检查 PNG、源稿和脚本的登记；构建无需运行 Aseprite。登记不包含用户自定义存档。

## 目录

```
public/assets/cat/
├── hd/                    # 320×320 猫素材
│   ├── breeds/            # 各品种的正面及打字层
│   ├── typing-front/      # 正视电脑、共用前爪与图层遮罩
│   ├── typing-falling/    # 当前三档打字的字母、表情与特效
│   ├── typing-v2/         # 历史 32 帧图集
│   └── typing-reference/  # 历史 12 帧图集与共用干净电脑
├── new_/                  # 320×320 橘猫待机与打字分层
└── masks/                 # 160×160 猫的换色遮罩与虹膜遮罩
```

- `hd/new_*.png` 是 320×320 的 HD 代素材，文件名保留 `new_` 前缀以区分代际。多帧图集及各版本的尺寸见[共用低抬爪打字动画](#共用低抬爪打字动画)。
- 160×160 猫素材仍用于基础坐姿/行走/打字骨架，HD 素材叠加在更高分辨率画布上。

## LibTV 橘猫素材

新橘猫素材来自画布项目 `2576e72bf0f04924a4720136c4ddec8b` 的「橘猫」「不同耳朵」「嘴鼻」「面部花纹」「配饰」「敲键盘」节点。「图片节点 6」的两个输出是打字草稿；六件配饰取自画布上的「配饰」。原坐姿由身体、基础头部和独立耳朵合成；虹膜遮罩只覆盖深棕色眼仁。两组打字共用同一个头部、电脑和尾巴。

用 LibTV MCP 以 `i-<节点 ID>-0.png` 保存这六张原图，再运行 `python scripts/extract-orange-cat.py ORIGINALS_DIR STAGING_DIR`（需要 Pillow、NumPy、SciPy）。脚本去掉原图里的棋盘底，按参考位置裁切和对齐，仅用最近邻取样。输出为 320×320 RGBA，alpha 仅为 0 或 255，保留原图颜色和描边宽度。将提取结果先保存到单独的中转目录，以免覆盖 Aseprite 重绘后导出的运行时图层。

| `muzzle` | CN02–CN04 | `CAT_muzzle_<ID>.png` |

### 独立额头花纹

猫外观的 `pattern` 字段只控制额头：`P00` 品种原额纹、`P03` 无额纹、`P01` 白额线、`P02` 双眉斑、`P05` 小菱纹、`P06` 眉斑加额线。品种预设使用 `P00` 以保持默认外观。M 字纹 `P04` 已下架，源稿和 PNG 仍登记在兼容组，旧配置映射到 `P03`。

每款的 Aseprite 源文件在 `art/cat-shared/forehead/`，身体、头部和耳朵参考层锁定，`forehead` 层可以单独编辑。共用 320×320 坐标，红通道表示深色纹，绿通道表示浅色纹，运行时按所选毛色上色。白额线收在额头，双眉斑不包含脸颊。`P03` 是清除原额纹、不叠加新纹。

`art/cat-shared/face-fur-patterns.aseprite` 保存 `forehead_region`、`face_region` 两个互不重叠的区域遮罩，以及三种独立脸侧毛纹。替换额纹使用独立遮罩。虎斑品种先补齐干净的额头底毛和轻阴影，三花、暹罗和布偶在连续的品种底色上直接添加额纹。更换毛皮纹统一处理脸侧、身体与尾巴。原外轮廓、眼鼻嘴和胡须受保护。

额头区域沿两耳之间的头型用 2 px 台阶收边，替换耳型的实心形状遮罩会保护耳折痕和内耳。三花、暹罗和布偶没有独立烘焙的额头条纹；使用原生毛皮时保留其连续的品种色区，只叠加所选额纹，避免把黑白块或重点色当成额纹清除。选择统一毛皮时才统一额头底毛；额纹图案与配色仍保持独立。


无额纹预览用 `markingLayout: clean-forehead` 记录两侧耳根的局部描边清理。其他当前额纹使用 `shared`。已有 `shared` 底稿按原合成还原，缺字段的历史存档按 `legacy` 还原整脸贴花及仅身体换纹，再提取用户修改。

### 正面鼻子与嘴巴

`art/cat-shared/front-noses.aseprite` 保存小方鼻、中鼻、大鼻和长鼻的独立图层与帧标签，编号为 `NO05–NO08`。导出命令为 `npm run assets:export -- cat.noses`。工作台在同一行提供鼻形和鼻色，圆角鼻 `NO02` 沿用原稿。鼻色按品种原色或独立色板着色，保留鼻尖的色阶。所有鼻形共用 320×320 正面坐标，鼻尖按高度接到所选嘴形的中心线，待机与三档打字共用。

`art/cat-shared/front-mouths.aseprite` 的 `mouth` 图层按编号 `CN05–CN09` 保存五种正面嘴形。工作台依次显示微笑、吐舌、凸凸嘴、严肃嘴、奔驰嘴，各品种默认微笑。用 `npm run assets:export -- cat.mouths` 导出五张 320×320 的透明嘴形 PNG，以及 `skin_cleanup.png`，到 `public/assets/cat/hd/face-parts/mouths/`。补色图按品种顺序使用四列 `faceTiles`，覆盖旧嘴残线与暗点。待机采用外观选中的嘴形，三档打字从同一套素材取用动作对应的嘴形，鼻形和鼻色独立。

`art/cat-shared/front-face-parts.aseprite` 中的旧四列图集继续提供圆角鼻、橘猫补色底层，以及供旧像素存档还原底稿的鼻形和嘴形。工作台将 `NO01`、`NO03`、`NO04` 分别映射到小方鼻、中鼻、大鼻，将 `CN01–CN04` 依次映射到凸凸嘴、吐舌、吐舌、严肃嘴。旧 `muzzle` 字段会同时恢复对应的鼻形和嘴形；还原历史底稿时保留原始编号。


### 共用听音乐动画

八个品种和登记了配色的同轮廓品种使用同一套 320×320、23 帧闭眼摆头动作，每帧 75 毫秒，单圈 1725 毫秒。当前外观先按待机坐姿分层合成，头和耳朵按统一锚点摆动，颈侧和白胸毛上缘跟随，爪子、下半身和尾巴保持待机像素。鼻嘴保留当前选择，全程使用独立的闭眼线条。用户笔迹随所在部位摆动，像素编辑器从待机底稿开始，耳机和音符作为临时效果。

`art/cat-shared/listening.aseprite` 保留已确认的橘猫参考和独立动画层。`npm run assets:export -- cat.listening` 从源稿导出耳机头带、耳罩、闭眼和音符四张局部图集，写入 `cat/hd/listening/`。头带和音符放在猫后面，耳罩放在前面。动作变换与帧时序在 `src/cat-listening.ts`，合成在 `src/render.ts`。

Mac 工作台有「听音乐」预览。桌宠沿用现有的音乐播放器检测来进入或退出该状态，打字、拖动和贴边优先，暂停动作结束后从正面恢复听音乐。

### 共用碎纸动画

选择拖入文件后的「删除」，文件成功移入 macOS 废纸篓后，桌宠播放一次共 12 帧、1585 毫秒的碎纸动作。贴边时先展开完整坐姿，演完回到原来的位置。动作结束后恢复当前桌宠状态。

`art/cat-shared/shredder.aseprite` 保存确认的分层源稿。执行 `npm run assets:export -- cat.shredder`，把道具、前臂与活动爪子导出到 `cat/hd/shredder/`。各品种共用动作坐标和道具，前臂和爪子从当前品种与毛色取色。头部、坐姿、配饰与尾巴取当前外观。机器遮住坐姿前爪，动画中的两只前爪跟随送纸动作，结尾使用共用微笑和闭眼线条。

### 共用压缩动画

把文件拖给桌宠并选择「压缩」后，ZIP 成功生成时播放一次共 18 帧、2015 毫秒的动作。双爪下压，收爪后箱盖和拉链自动闭合，最后闭眼微笑。八个品种复用动画，前臂和爪子按当前毛色取色。贴边时先展开坐姿，播放完成后恢复贴边。

`art/cat-shared/zip.aseprite` 是确认的分层源稿。执行 `npm run assets:export -- cat.zip`，导出 `cat/hd/zip/` 下的纸箱道具、前臂和活动爪图集。收爪帧按箱体遮挡导出可见的爪子像素。

### 共用格式转换动画

把文件拖给桌宠并选择目标格式后，转换成功时播放一次 20 帧、2465 毫秒的动作。猫咪送入白色文件，机器亮起后吐出粉色成品，猫咪接住、放下并闭眼微笑。各品种共用动作和道具，前臂和爪子使用当前品种和毛色。

`art/cat-shared/convert.aseprite` 保存确认的分层源稿。执行 `npm run assets:export -- cat.convert`，把道具、前臂和活动爪图集导出到 `cat/hd/convert/`。

### 共用低抬爪打字动画

八个品种使用 `front-v6` 正视打字。身体、花纹、脚和尾巴取当前待机形象，爪子随当前毛色变化。三档的字母都先向两侧弹起，再落到电脑底边的高度，触地后轻弹并散开。

| 工作台动作 | 模式 | 每帧 / 整圈 | 左右落爪间隔 / 单爪遮挡时长 | 字母与表情 |
| --- | --- | --- | --- | --- |
| 慢敲键盘 | `gentle` | 70 ms / 4480 ms | 560 ms / 280 ms | 每圈弹出 8 个字母，微笑 `CN08` |
| 比较快 | `fast` | 40 ms / 2560 ms | 320 ms / 160 ms | 每圈弹出 12 个字母，睁眼、严肃嘴 `CN06`、汗水 |
| 特别快 | `frenzy` | 20 ms / 1280 ms | 160 ms / 120 ms | 每圈弹出 18 个字母，电脑逐渐升温，变红后持续冒汽，全程挤眼、奔驰嘴 `CN07` |

`art/cat-shared/typing-front.aseprite` 提供正视电脑、慢档和比较快共用的 16 帧爪部图集，以及旧版字母。`art/cat-shared/typing-gentle-falling.aseprite`、`art/cat-shared/typing-fast-falling.aseprite` 和 `art/cat-shared/typing-frenzy.aseprite` 是 320×320、64 帧的三档分层源稿。比较快档源稿包含 `letter_bursts` 和 `letter_landings`。特别快档额外导出爪部停顿、电脑热色、蒸汽与敲击火花、汗水和旧版挤眼嘴形。新版特别快档直接复用已有的挤眼图层及奔驰嘴。爪部透明度用于定位左右爪的自定义笔迹。

使用 `npm run assets:export -- <素材组>` 更新 `cat/hd/typing-falling/`，三档素材组依次为 `cat.typing.front-v4.gentle`、`cat.typing.front-v6.fast`、`cat.typing.front-v4.frenzy`。各档字母与落地粒子合在各自的透明图集里，渲染时绘制在猫和电脑后方。特别快档的电脑从入档开始独立升温，约 600 毫秒后保持红色，蒸汽继续循环。热色随电脑一起应用用户笔迹或擦除。预览以 `frenzyHeatFrame` 保存热状态，旧预览省略此字段，仍以当时的热色和蒸汽重建底稿。

真实键盘按最近一秒的输入频率选择档位，达到 5 次进入比较快，达到 9 次进入特别快；特别快降到 6 次退出，比较快降到 2 次退出。切档保留动作相位。猫停打约 1 秒后回到待机。

#### 历史正视和侧面动作

工作台新预览记录 `typingAnimation: front-v6`。旧 `front-v5` 的比较快档使用原字母轨迹。旧 `front-v4` 使用原先会从睁眼微笑切换到挤眼的底稿。历史 `front-v3` 继续从原正视资源还原，包括旧字母轨迹及特别快档的四帧遮挡。旧的 `reference-v2` 使用 `art/cat-shared/typing-v2/` 下的 32 帧源稿，`cat.typing.reference-v2.shared` 导出共用前臂、爪子遮罩及补片，其他两组导出表情和汗水。侧面电脑由 `cat.typing.laptop` 导出，用于重建历史存档的 `laptopVersion: clean`。更早的存档按原图还原，包括原橘猫电脑层中曾经与电脑合绘的尾根连接像素。旧档按相应版本重建底稿后再提取笔迹。

#### 历史 shared 动画与效果源稿

历史 `shared` 的温柔打字和疯狂打字共用 12 帧轨迹，由原温柔打字第 0 帧左爪、第 2 帧右爪生成整数像素中间姿势，循环为 1000 ms 与 360 ms。之后的 `reference` 为三档 12 帧手绘图集，周期 1000/600/360ms。这两代均保留用于旧底稿重建。

历史效果源稿 `art/cat-shared/typing-effects.aseprite` 保存 `effort_eyes`、`sweat` 和橘猫旧眼睛的底毛补片 `orange_eye_patch`，身体与头部是锁定参考层。四帧分别是休息、出汗、下落、消退；导出一张挤眼、三张汗水、一张补片，共五张透明 PNG。


部分早期品种的头底仍含深棕色圆瞳与旧眼圈残留。当前版本先识别需要清理的头底，再按完整睁眼图层的轮廓补齐邻近毛色，缓存干净的挤眼底图。各历史版本按保存时的底图还原。新增品种宜使用干净头底，并将眼睛、虹膜和高光分层，便于复用表情。

### 橘猫打字原始底稿

`art/orange-cat/typing/gentle.aseprite` 和 `fast.aseprite` 各有四帧，帧时长分别为 250 ms 和 90 ms。两组锁定同一份身体、尾巴、头部和电脑，胸前与前爪动作在 `torso_motion` 和 `paws_front` 层。应用使用可换装的头部图层，最后绘制电脑，遮住与键盘交叠的爪子下缘。

打字使用待机的头部尺寸与坐标。身体、前爪和电脑按颈部和底边对齐后，以最近邻方式呈现。源稿保留原始动作坐标，旧版打字姿势保存的像素编辑会在载入时投影到当前坐标。

两个历史导出组为 `cat.orange.typing.gentle` 和 `cat.orange.typing.fast`。


这些原始四帧保留用于还原 `legacy` 四帧、`shared` 12 帧的旧像素编辑存档，并提供历史版本的身体与电脑图层。

### 黑猫、三花猫与暹罗猫

源稿在 `art/cat-breeds/`。每个品种的 `*-front.aseprite` 有独立的身体、头部、五套耳朵、眼睛与虹膜遮罩、四套嘴鼻和三套可选花纹。打开时显示默认组合，替换零件时切换相应图层。历史慢打、快打各有四帧源稿，锁定头部、身体和电脑，动作层保留各品种的爪部毛色。三花的右侧行走源稿为 `calico-right-walk.aseprite`，在共用的行走坐标上单独绘制斑块。

正面和打字图层在 `public/assets/cat/hd/breeds/CC02/`、`CC03/`、`CC04/`。正面运行图层以源稿图层名导出为 320×320 PNG。当前打字合成 `typing_body`、`typing-v2/` 共用动作图集、可换装的头部及独立表情和共用的 `typing-reference/laptop.png`，电脑遮住爪子下缘；原有 `typing_arms_fast_<帧号>` 与 `typing_front_<帧号>` 保留用于旧存档还原。右侧三花颜色层放在 `public/assets/cat/masks/`，以 `_calico_right.png` 结尾。

红蝴蝶结、蓝色小鱼帽、黄色星星发卡和蓝色鸭舌帽共用正面坐标。鸭舌帽在橘猫中使用 `A06`，其他三种猫使用 `A07`。黑猫、三花和暹罗的旧版 `A06` 打字猫配饰加载时会切换为 `A00` 无配饰。打字动画由动作控制。

默认眼睛的小高光从 `art/cat-breeds/eye-glints.aseprite` 导出。橘猫用 `CAT_eye_glints.png`，黑猫、三花猫和暹罗猫共用 `eye_glints.png`。侧面的高光从 `walk-eye-glint.aseprite` 导出到 `walk_eye_Y01_glints.png`。

### 英短蓝猫、美短、狸花猫与布偶猫

这四个品种使用 LibTV 项目 `375001d11739451c9f5549e520831c34` 中同名节点的毛色和花纹，套用已验收的 320×320 正面轮廓、眼窝与脚底锚点。分别对应 `CC05`、`CC06`、`CC07` 和 `CC08`，源稿前缀为 `british-blue`、`american-shorthair`、`li-hua` 和 `ragdoll`。

每个 `*-front.aseprite` 包含独立的身体、干净头底、立耳、眼睛、虹膜遮罩、瞳孔区域、嘴、鼻子和高光。四帧标签 `CN01`–`CN04` 保存四组嘴鼻零件，应用可独立组合鼻子和嘴巴。历史 `*-typing.aseprite` 包含 `gentle` 和 `fast` 标签，各四帧。身体、前爪和电脑保存原始动作坐标，锁定的头部参考按旧版动作比例放置，工作台统一对齐到待机尺寸。当前三档打字与其他品种共用 `typing-v2/` 图集，旧动作层继续用于存档还原与品种毛色取样。

运行时 PNG 位于 `public/assets/cat/hd/breeds/<编号>/`，嘴鼻图集位于 `public/assets/cat/hd/face-parts/<编号>.png`。替换耳型和其他表情沿用共用零件及各品种的配色。英短蓝猫的素材组是 `cat.breed.CC05` 和 `cat.breed.CC05.typing`。

### 仅配色接入同轮廓品种

在 `src/cat-breeds.ts` 的 `colorCatBreeds` 加一条记录。以下示例依次指定底毛、花纹和浅毛三色。

```ts
CC09: { name: '示例猫', colors: ['#A69182', '#755D55', '#F7E9DB'] },
```

品种编号用于保存和恢复，发布后保持编号稳定。默认套用橘猫的轮廓和部件，也可用 `template: 'CC04'` 一类的字段复用现有品种的轮廓、原生花纹位置和外观默认值。工作台会自动列出该品种及色块。头身、耳尾、描边和三档打字前爪共用素材并按登记颜色着色。毛色搭配选回「品种原色」时恢复这套配色。

需要新轮廓、比例或原生花纹位置的品种，仍按对应零件和遮罩登记素材。沿用现有花纹位置的配色品种只需上述一条记录。


### 共用正面耳型

正面待机与三档打字共用同一套 320×320 耳型坐标。每个品种提供一份 `ear_upright.png`，建立默认立耳、额头色块和脸侧接缝。从中保留固定额头，再用橘猫已验收的四份替换耳型作轮廓。新增同一坐标体系的品种时，在 `src/cat-ears.ts` 配置画面左、右耳的描边、阴影、毛色和浅色。三花的左右耳可使用不同配色，暹罗可为双耳指定重点色。旧品种的四份替换耳朵 PNG 用于识别早期像素编辑存档里的底稿。

工作台的耳形和内耳色在同一行，内耳和鼻子共用一套色板，可以独立选择。`earColor` 默认使用品种原色。指定颜色时，渲染器按原耳层的粉色区域着色，沿用原有透明度和明暗。

`art/cat-shared/front-ear-masks.aseprite` 对应四款替换耳型。每个标签对应一帧，`head_reference`、`upright_reference` 和 `shape_reference` 是锁定的对位参考。画面左、右耳各有独立遮罩。遮罩中的实心白色使用完整耳朵色，灰色用于耳根过渡，未覆盖的区域保留品种底稿的像素。耳型轮廓有增减的位置也用实心白色标记，让合成器能擦除旧耳尖或加上新轮廓。侧面使用自己的像素形状和锚点。


### 共用尾巴

工作台提供 `CT05 直尾`（默认）、`CT06 短尾`、`CT07 L字型弯尾`、`CT08 Z字型弯尾`、`CT09 卷环型尾`，形状从用户提供的 LibTV 尾巴参考图绘制。

五款尾巴共用源稿 `art/cat-shared/front-tails.aseprite`，用 `npm run assets:export -- cat.tails.shared` 导出待机、打字两组 320×320 形状与花纹 PNG。新打字尾巴在已对齐的正面画布上绘制，三档打字共用同一组尾巴；原打字尾巴和移除遮罩仍使用各自的旧动作坐标。

`public/assets/cat/hd/tails/` 中的形状 PNG 使用共用橘色阶，花纹 PNG 的红、绿、蓝通道分别对应细虎斑、经典虎斑和点状虎斑。`src/cat-tail.ts` 按品种、毛色搭配与毛皮花纹上色。原尾遮罩沿右后腿外侧的描边分割，替换尾巴合成在身体、前爪和电脑后方。卷环中心留透明孔。

旧选项映射到最接近的新尾型：`CT01 → CT05`、`CT02 → CT06`、`CT03 → CT05`、`CT04 → CT07`。旧外观没有尾巴字段时也使用直尾。旧像素存档的底图匹配保留原编号，缺少尾巴字段的旧底图按 `CT01` 还原；`cat.tails` 保留旧尾形和共用移除遮罩。这样旧底图的尾巴不会被识别为用户笔迹，已有分部位笔迹仍直接读取。

当前预览记录 `tailArtVersion: clean`。`cat.tails.reference` 用同一份源稿中隐藏的 `previous_tail_edges` 图层还原补描边前的尾型；重画前的 `CT05–CT09` 底图由 `cat.tails.initial` 还原，源稿保存在 `art/cat-shared/tails/front-tails-initial.aseprite`。无元数据的旧 PNG 会在提取笔迹时比较各版尾巴。


### 毛色搭配

猫配置中的 `palette` 对应品种底稿，`coat` 对应工作台的整套毛色。`src/cat.ts` 中每套搭配声明底毛、花纹和浅毛三个色值，工作台色卡和正面合成共用这组数据。「毛色搭配」自动列出已登记品种的色板，使用 `breed:<品种编号>` 保存。选用色板时，颜色应用到当前品种和当前花纹位置。原色直接读取现有底稿。

工作台选择品种时，使用该品种的整套预设覆盖外观选项，毛色搭配恢复 `native`，毛皮与额纹也恢复品种默认；不沿用之前选择的配色。之后仍可继续修改外观。姓名等档案信息和独立自定义笔迹分别保留，不属于品种外观重置范围。

`src/cat-coat.ts` 根据每种底稿的色阶换色，沿用虎斑、三花斑块或重点色的位置。待机和打字共用配色，打字的前爪和电脑边缘上的少量毛发也用同一套色阶。添加配色时沿用现有分层 PNG。

`src/cat-outline.ts` 为非原色搭配生成同色系描边，以花纹色推导深色线条；浅毛色的线条相应柔和，冷色毛发不再保留暖棕边。头部、当前耳型、身体、前爪与当前尾型分别使用原始橘猫图层识别线稿，再在毛色/毛纹合成后着色。不能按最终图像的深色像素全局替换，否则会误伤深毛、斑块或瞳孔。描边不改变 alpha、轮廓和位置，眼睛、鼻嘴、汗滴、配饰和电脑保留各自颜色，用户笔迹最后叠加。新增同坐标体系的品种和毛色可直接复用；改变轮廓时需要提供对应的线稿参考。

像素编辑源信息记录 `outlineVersion: adaptive`。缺少此字段的旧保存按 `original` 重建原底图，再提取真实编辑内容；无元数据 PNG 会匹配新旧两种描边。`coat: native` 在两种版本下逐像素一致。

### 毛皮花纹

`bodyPattern` 控制躯干和四肢，脸颊、额头和尾纹分别用 `cheekPattern`、`pattern`、`tailPattern`。各部位可选品种原纹、无附加纹路或相应的可替换图案。细虎斑使用窄条，经典虎斑使用宽纹和侧腹涡纹，点状虎斑使用断开的斑点。 [CFA 猫毛色与花纹说明](https://cfa.org/coat-color-descriptions/)

三花、暹罗、布偶可在 `faceBase` 中切换品种原底与均匀底色。其他内置品种的脸部底纹显示为均匀底色，脸颊与额头的花纹仍可分别选择。`bodyBase` 独立选择品种原底或纯色身体。工作台将旧联动选择带入三处纹理控件，像素编辑底稿根据保存的字段重建。

`art/cat-shared/front-body-patterns.aseprite` 的每个标签对应一张身体或打字动作图层。`body_reference` 是锁定的对位参考，三种花纹各有独立图层。导出时，细虎斑、经典虎斑和点状虎斑分别写入红、绿、蓝通道。

脸侧纹由 `head-patterns/face_patterns.png` 使用相同的 RGB 通道约定。三花、暹罗和布偶直接用已有头、身体和尾巴的品种色块打底，再按局部底色叠加统一花纹遮罩。额头独立叠加，品种色块可跨额头与脸侧连续分布。其他品种先用干净底毛替换旧纹，再给新纹着色。待机与三档打字共用这套素材。

纯色身体同时替换从白胸延伸到头部图层的白毛。坐姿源稿的头身接缝用于识别这一小段白毛，三花这类延伸进脸部的大面积白斑仍由脸部底纹控制。三花选择均匀脸底时，接缝沿用共享底稿的白胸边界。品种原底沿用源稿上的白胸。

纯色身体搭配品种原纹时，花纹强度取自相应品种的身体底稿。橘猫、黑猫、美短和狸花保留各自的条纹位置和宽度。重点色和三花色块属于品种原底。

碎纸、压缩和格式转换的前臂、爪子共用同一条前肢的自定义斑纹。渲染根据动作图层把斑纹投到对应部位，独立前爪斑仍叠在爪子上。

自定义编辑源记录 `furPatternColors: independent-fur`。旧档的 `connected-chest` 和 `clean-face` 重建各自版本的颈部像素和原纹，`breed-pigment` 重建修整眼缘之前的底图，`calico-chest` 重建短白胸试稿。均匀脸底的眼缘使用当前脸部毛色，原眼白和瞳色仍取眼部图层。旧值 `matched` 和 `original` 也按当时的合成方式提取笔迹。

### 新稿分层

工作台的动作素材以正面待机，以及慢敲键盘、比较快、特别快三档打字为维护范围。

| 分组 | Aseprite 图层 | 代码用途 |
| --- | --- | --- |
| 头部 | 干净头底、左耳、右耳、耳根遮罩、额纹、左右颊纹、胡须 | 统一头部原点，品种花色走独立色区，耳朵共享形状和配色 |
| 五官 | 眼白、瞳孔、虹膜遮罩、小高光、鼻子、嘴 | 单换瞳色、表情、鼻色或嘴形，眼神跟随只移动高光 |
| 身体 | 躯干、胸口花色、尾巴、左右前爪 | 动作帧复用静态躯干，按帧替换或移动前爪 |
| 配饰和道具 | 后层、前层、需要遮挡的独立片 | 用耳根、颈部或前爪锚点定位，按动作控制遮挡 |

源稿先把需要独立替换、移动或遮挡的部位拆开。各层用同尺寸透明画布和统一坐标导出。已经画进底稿的旧五官须先移出，并补齐下面的干净底色。共享骨架的新品种可以提供配色和花色遮罩，同组的外形与动作模板可以直接复用。外轮廓、比例或遮挡明显不同的品种需要自己的对应零件。

### 左右眼瞳色

工作台按预览画面的左、右分别提供瞳色菜单。每只眼可选单瞳或双瞳；单瞳使用基础瞳色，双瞳可以另选内层颜色。渲染按画布中线拆分现有双眼遮罩，打字和待机共用。特别快打字时仍绘制挤眼表情。

配置用 `leftEyeColor`、`leftInnerPupil`、`leftInnerEyeColor` 和对应右眼字段保存各项选择。每个缺失字段沿用旧版的 `eyeColor`、`innerPupil` 或 `innerEyeColor`，旧像素存档可按原始瞳色重建底图。

### 自定义笔迹

新存档的 `.source.json` 使用 `pixelEdits` 记录各部位的着色和擦除像素，PNG 用作缩略图。左右耳、左右前爪和尾巴使用各自的局部坐标，合成时按当前零件的轮廓对位；头脸、躯干、电脑和画布各有自己的笔迹层。待机时隐藏电脑笔迹，再进入打字时重新显示。旧存档继续按原格式加载，在像素编辑器重新保存时写入分层笔迹。两种格式都保存在用户的应用数据目录。

## 命名约定

- `<view>_<part>[_<id>][_<slot>].png`
  - `view`: `sit`、`walk`、`type`
  - `part`: `body`、`head`、`ears`、`ear_CE02`、`eye_Y05`、`mouth_CN02` 等
  - `slot` 用于基础猫毛色遮罩，取 `g`（主色）、`s`（阴影）、`l`（高光）、`w`（浅毛）、`d`（深毛）。
- 虹膜遮罩统一为 `*_iris.png`，只保留 alpha，用于换瞳色。眼神跟随移动独立的小高光图层。
- 所有分层 PNG 的单帧必须与所在代际的画布尺寸一致：基础层 160×160，`cat/hd/` 为 320×320。多帧图集按导出脚本约定排列，`typing-reference/` 的动作与汗水图集为 320×3840。

## 新增一个猫零件

1. 在 `src/pet-assets.ts` 登记选项编号、源稿、导出方法和输出尺寸。只有改变接缝或遮挡时，才需要调整相应的合成规则。
2. 通过 `assets:export` 导出到审核目录，确认后更新运行时 PNG。
3. 运行 `assets:check`、构建与自检，核对组合、动作和旧存档。
