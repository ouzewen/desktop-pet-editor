# 宠物形象编辑器 · G2a 柴犬正面样板

本次审核使用 M1 柴犬预设 `preset_m1_12`。正面坐姿按 160 px 原画逐格描摹，按身体、头、耳朵、眼睛、嘴鼻、卷尾和花纹拆成独立 PNG。运行时由 Canvas 按层合成，换色只覆盖三种毛色槽位的 PNG 遮罩。

## 本地运行

需要 Node.js 22.12+ 或 24。

```sh
npm ci
npm run dev
```

打开终端里的本地地址。默认显示柴犬。可用 `npm run build` 做生产构建，或用 `npm run preview` 预览构建结果。

- [图层目录](public/assets/)内包含 5.1 逐名列出的七张主体图层及配置文件。另附 E02、E03、Y02、Y03、N02 五张换件验证图层。

在「换细节」切换耳朵 E01/E02/E03、眼睛 Y01/Y02/Y03、嘴鼻 N01/N02 或花纹 P02/P00。检查接合处是否露底，再切回柴犬预设。到「起名」导出 ZIP，解压后用右上角「导入 JSON」恢复形象。

G2a 沿用原有选项和配置校验。缺少 G2b 图层的选项仍会出现，预览画布标题会列出待交付编号，导出时会报告缺件。P02 的白颊边缘和眉斑在头部局部合成，头部再叠到身体上，因此花纹不会被不透明的头底遮住。原画中已出现的额线随 P02 保留，用于原画对照。

## 已核验

Chrome 中实测六次换件或花纹切换并切回、白区和鼻眼颜色不会被毛色遮罩覆盖、PNG 与 JSON 都可导出，JSON 重导后画布和 1× 导出逐像素一致。导出为 160、320、640 px，最近邻、四角透明、全图二值 alpha。柴犬成品含透明共 11 色，外接范围与 160 px 原画一致。TypeScript 检查及 Vite 生产构建通过。

原画带抗锯齿及较多过渡色，限色描摹版的边缘和细部有所差异，请以 4× 并排图验收。跑步和打字属于后续 G2c，其他 M1 零件属于 G2b。
