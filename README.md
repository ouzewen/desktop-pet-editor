# 宠物形象编辑器 · M1 样板

G2 评审版本 v0.1.0。只实现 M1 标准短毛的正面坐姿，以及左跑、右跑和打字样板。

## 本地运行

需要 Node.js 22.12+ 或 24。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。发布构建可执行 `npm run build`，再用 `npm run preview` 本地预览。

## 试用路线

1. 在「选框架」切换柴犬、比格犬或中华田园犬。在「换细节」修改耳朵、嘴鼻、尾巴、眼睛、毛色或花纹。
2. 切换「向左跑」「向右跑」「打字」。可以暂停并逐帧检查。左跑 6 帧，右跑逐像素镜像。打字 4 帧，前爪交替触键，身体固定。
3. 在「起名」输入 1–8 字，点击「导出 PNG + JSON」。解压后可取得静态正面透明 PNG（160、320、640 px）和 `pet-config.json`。用右上角「导入 JSON」恢复同一形象，再切换动作。
4. 也可直接导入 [比格犬样例 JSON](fixtures/pet-config.json)，与 [1× 参考 PNG](fixtures/pet-1x.png) 对比。

## 变更说明与实现口径

- 按 G1 定稿落地 M1 的正面锚点、C01–C08 色值、两像素描边、固定眼色与白区阴影。图层素材在 Canvas 渲染器内按模板合成。
- 侧跑使用样板自定的左向尾根基点 `(105, 84)`，纵坐标随各帧起伏。正面打字在触键帧让头及五官一起下移 2 px。跑步 88 ms/帧，打字 145 ms/帧。
- 配置采用 `version: 1`、`frame: "M1"`、`accessory: null`，使用映射表的模块编号。固定槽位直接绘制，眼睛使用独立配色，鼻色与白区使用定稿表的独立槽位。
- 样板通过编程绘制轮廓并在 160 px 画布上硬化像素。目前形象与动作都在网页评审，桌宠客户端接入和 G3 全量校验留待后续关口。

## 本地核验

Chrome 浏览器通过三预设编辑与渲染检查、三档 PNG 透明度和最近邻像素检查、比格犬改眼型后的 JSON 导出与重导比对、三预设共 18 对左右帧逐像素镜像比对，以及三预设与八套颜色的组合渲染检查。经 TypeScript 类型检查及 Vite 生产构建。
